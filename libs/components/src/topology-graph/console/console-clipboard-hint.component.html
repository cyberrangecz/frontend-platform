How to paste to shell in GUI

  1. Copy the text outside the console.
  2. Press {{ pasteModifierLabel }} + V to pass it to the session.
  3. Paste with the shell's own shortcut, usually Ctrl + Shift + V.

Why?

The browser guards your clipboard against sites logging every string you copy while the page is open. Its contents are revealed to the page only once you issue a deliberate paste command yourself.
